# ScreenSearchTool
![fffff20-ezgif com-video-to-gif-converter](https://github.com/user-attachments/assets/ae84c568-1b43-45fb-921f-40dafec886e2)

ScreenSearchTool là ứng dụng tiện ích trên Windows, cho phép bạn chụp màn hình theo vùng chọn, tích hợp khả năng trích xuất văn bản đa ngôn ngữ, dịch thuật tức thì, tìm kiếm, và hỗ trợ phân tích bằng AI (Gemini - API Key) ngay lập tức từ bất kỳ nơi nào trên máy tính của bạn.

## Tính năng nổi bật

- Chụp màn hình theo vùng chọn/thời gian thực - trích xuất văn bản tự động.
- Crop vùng đã chọn và tái sử dụng.
- Hỗ trợ nhiều ngôn ngữ, có chế độ "Tự động phát hiện" và dịch văn bản sang 100+ ngôn ngữ khác nhau (tessdata: Tiếng việt/ tự động phát hiện. Paddle: Các ngôn ngữ còn lại)
- AI Gemini API: Tóm tắt và giải thích văn bản
- Tự động copy văn bản đã được trích xuất vào bộ nhớ tạm.
- Hotkey toàn hệ thống: `Shift + D` để bật/ẩn ứng dụng,...
